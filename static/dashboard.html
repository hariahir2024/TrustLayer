📋 How to Collect Intruder Data

  1. Have a friend/family log in as a test user (use their own account).
  2. Ask them to complete 2–3 sessions typing deliberately differently — like an intruder would (slow, hesitant, unfamiliar).
  3. After they finish, come to the Real-Time Monitor tab and click on their session.
  4. In the session drawer, use the "Mark as Intruder" button to retroactively label those sessions.
  5. Repeat until you have 20+ intruder-labeled sessions across different users.
  6. Run python scripts/retrain_xgb_augmented.py to retrain XGBoost with real data.
Multi-device tip: Each (user, device) pair builds a separate profile. Desktop and mobile will NOT interfere with each other's baselines.
