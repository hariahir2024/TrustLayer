Biometrics Guide

Keystroke Dynamics

Key Hold (Dwell) Time The total duration a single physical key is held down. Reflects finger weight and key reach cadence. Anomalous changes suggest credential sharing or hesitation.
Flight Time (Transition Delay) The gap between releasing key 1 and pressing key 2. Touched-typed familiar words have tiny transition flight times, whereas un-memorized credentials yield high flight delays.
Backspace Correction Rhythm The speed and frequency at which typos are corrected. Legit users perform deletes fluidly using motor memory; intruders hesitate heavily during corrections.

Mouse & Cursor Kinematics

Sinuosity & Path Curvature The ratio of path distance to straight-line distance. Human hands produce natural arcs (high sinuosity), whereas remote desktop clients and automation scripts move in absolute straight lines.
Jerk (Acceleration Tremors) The rate of acceleration changes ($d^3x/dt^3$). Micro-tremors in hand muscles cause non-zero jerk. Direct API injections or emulator sweeps move with perfect mathematical velocity (zero jerk).
Target Overshoot & Correction The action of passing target coordinate borders and re-centering before clicking. Normal users overshoot frequently. Bot scripts hit the target pixel-perfectly without overshoot.

Cognitive Heuristics

Application Familiarity (Form Flow) The speed of moving from one form element to the next. High familiarity implies fluid spatial navigation. Fraudsters and socially engineered victims display heavy hesitation, stopping to read instructions or follow external voice coaching.
Paste-to-Type Ratio The percentage of fields populated via clipboard copy-pasting. Excessive pastes suggest compromise credential stuffing, while typical account owners type details manually.
Coached Victim Indicators Frequent focus shifting (switching apps to read OTPs), simultaneous phone calls, or long idle cycles on simple transaction screens. Highly indicative of active voice scams.
